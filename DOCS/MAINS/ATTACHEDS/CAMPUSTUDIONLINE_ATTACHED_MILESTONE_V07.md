- **Tareas:**
    - **Re-arquitectura del Admin de `content_automation`:** Implementar una vista de administración jerárquica y visual que permita una gestión intuitiva de las tareas de generación de contenido, mostrando su estado (pendiente, completado, fallido) y facilitando el acceso a los resultados.
    - **Visualizador de Disponibilidad de Contenido:** Desarrollar una vista, reutilizable en `content_automation` y `academic_directory`, que muestre el árbol académico completo, marcando visualmente (ej. colores) las asignaturas que ya disponen de contenido. Incluirá una funcionalidad para que los usuarios puedan solicitar la creación de contenido para las asignaturas vacías.
    - **Creación de la Aplicación de Feedback:** Desarrollar una nueva aplicación Django que centralice las interacciones de los usuarios con el equipo de desarrollo, incluyendo un buzón de sugerencias, un formulario para reportar bugs y una página de contacto.
