# REGISTRO DE ARQUETIPOS DE EVALUACIÓN (VERSIÓN REALISTA UGR)

## I. ARQUETIPO: CEFR_LANGUAGES (Modelo CLM/HSK)

### A. ITINERARIO "MINOR" (Chino/Japonés/Árabe - A1-A2)
*   **PROHIBICIÓN ABSOLUTA:** Queda terminantemente prohibido generar un 'Reading Stimulus' (texto largo de referencia). 
*   **ESTRUCTURA ATÓMICA:** Cada pregunta debe ser independiente. Si requiere contexto, este no superará los 15 caracteres.
*   **FOCO:** Gramática, vocabulario y sintaxis aplicada. No se pregunta sobre "objetivos del curso".
*   **Estructura Obligatoria:**
    1.  **Bloque 1: Vocabulario y Uso (5 ítems):** QT_SEL.
    2.  **Bloque 2: Estructura Gramatical (5 ítems):** QT_CLZ_OPT.
    3.  **Bloque 3: Construcción de Frases (5 ítems):** QT_ORDER.
    4.  **Bloque 4: Caligrafía (2 ítems):** QT_PROD + REQ_DUAL.

### B. ITINERARIO "MAIOR" (CertAcles B1-C2)
*   **Reading Stimulus:** Permitido y obligatorio.
*   **Inmersión:** 100% Idioma Objetivo.
