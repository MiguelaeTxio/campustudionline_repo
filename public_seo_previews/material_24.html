def operaciones_con_diccionarios(diccionario):
    # Calcular la cantidad de elementos en el diccionario
    cantidad_elementos = len(diccionario)
    
    # Encontrar la clave con el valor máximo y mínimo

    valor_maximo = diccionario[clave_maxima]

Una pila es una estructura de datos de tipo LIFO (Last In, First Out), donde el último elemento en entrar es el primero en salir.

Ejemplo Visual

Imagina una pila de libros donde:

  1. Primero colocas el libro verde.
  2. Encima pones el libro azul.
  3. Finalmente, colocas el libro rojo.

En este caso, el rojo es el último en entrar y será el primero en salir.

Implementación en Python

A continuación, implementamos una pila usando una clase en Python.

Definición de la Clase Pila

In [3]:
class Pila:
    def __init__(self):
        self.elementos = []

    def esta_vacia(self):
        return len(self.elementos) == 0

    def insertar(self, elemento):
        self.elementos.append(elemento)

    def eliminar(self):
        return self.elementos.pop()

    def consultar(self):
        return self.elementos[len(self.elementos) - 1]

    def tamaño(self):
        return len(self.elementos)

Explicación de los Métodos

  • __init__: Inicializa una lista vacía para almacenar los elementos de la pila.
  • esta_vacia: Comprueba si la pila está vacía.
  • insertar: Añade un elemento a la pila.
  • eliminar: Elimina el último elemento añadido (pop).
  • consultar: Devuelve el elemento en la cima sin eliminarlo. -tamaño: Devuelve el número de elementos en la pila.

Ejemplo de Uso

Veamos cómo usar la clase Pila en un ejemplo práctico:

In [4]:

p = Pila()

# Insertar elementos
p.insertar("libro verde")
p.insertar("libro azul")
p.insertar("libro rojo")

# Consultar el tamaño de la pila
print(p.tamaño())  # Output: 3

# Consultar el elemento en la cima
print(p.consultar())  # Output: libro rojo

# Eliminar elementos
p.eliminar()  # Elimina "libro rojo"
p.eliminar()  # Elimina "libro azul"

# Consultar el tamaño actual de la pila
print(p.tamaño())  # Output: 1

# Verificar si la pila está vacía
print(p.esta_vacia())  # Output: False

# Eliminar el último elemento
p.eliminar()  # Elimina "libro verde"

# Verificar si la pila está vacía
print(p.esta_vacia())  # Output: True

Concepto Resumido

Una pila es una estructura de datos LIFO (Last In, First Out), donde el último elemento en entrar es el primero en salir. En este ejemplo de Python, hemos creado métodos para:

  1. Insertar elementos.
  2. Eliminar elementos.
  3. Consultar el elemento en la cima.
  4. Verificar si la pila está vacía.
  5. Medir el tamaño de la pila.

Esta implementación es ideal para situaciones donde se necesita controlar los elementos en orden inverso al que se añadieron.

Una cola es una estructura de datos de tipo FIFO (First In, First Out), donde el primero en entrar es el primero en salir.

Ejemplo Visual

Un ejemplo clásico es una cola de personas esperando un autobús:

  1. La primera persona en llegar es la primera en subir al autobús.
  2. Las demás personas se colocan al final de la cola, respetando el orden de llegada.

Este mismo concepto se aplica a una estructura de datos de tipo cola en Python.

Concepto Resumido

Una cola es una estructura de datos FIFO (First In, First Out), donde:

  • El primero en entrar es el primero en salir.
  • Los nuevos elementos se añaden al final de la cola.
  • Los elementos se eliminan desde el principio de la cola.

Esta implementación es útil para situaciones como:

  • Personas esperando en una fila.
  • Procesos en una cola de impresión.
  • Tareas en una lista de espera.

Descripción

La estructura de datos Deque (Double-Ended Queue) es una mezcla entre una pila (stack) y una cola (queue). En una deque, puedes:

  • Insertar elementos tanto por el principio (cabeza) como por el final (cola).
  • Eliminar elementos tanto por el principio (cabeza) como por el final (cola).

Diagrama de una Deque

Cabeza                            Cola
| Insertar / Eliminar | ... | Insertar / Eliminar |

class Deque_:
    def __init__(self):
        self.items = []

    def append(self, item):
        """Agrega un elemento al final del deque."""
        self.items.append(item)

    def appendleft(self, item):
        """Agrega un elemento al inicio del deque."""
        self.items.insert(0, item)

    def pop(self):
        """Elimina y devuelve el último elemento del deque."""
        if not self.is_empty():
            return self.items.pop()
        else:
            raise IndexError("pop de una deque vacío")

    def popleft(self):
        """Elimina y devuelve el primer elemento del deque."""
        if not self.is_empty():
            return self.items.pop(0)
        else:
            raise IndexError("popleft de una deque vacío")

    def is_empty(self):
        """Devuelve True si el deque está vacío, False de lo contrario."""
        return len(self.items) == 0

    def size(self):
        """Devuelve el tamaño del deque."""
        return len(self.items)

    def __str__(self):
        """Devuelve una representación en cadena del deque."""
        return f"Deque_({self.items})"

Listas Simplemente Enlazadas en Python

¿Qué es una Lista Simplemente Enlazada?

Una lista simplemente enlazada está formada por nodos que están conectados entre sí de manera secuencial.

Cada nodo contiene:

  1. Datos: La información que almacena el nodo.
  2. Referencia (o puntero): Una referencia al siguiente nodo en la lista.

A diferencia de las listas nativas de Python, que permiten acceder directamente a cualquier elemento por su índice, en una lista enlazada debes "navegar" nodo por nodo para llegar a un elemento. Esto la hace más eficiente para operaciones como la inserción y eliminación (cuando ya tienes la referencia al nodo), pero más lenta para acceso aleatorio.

Ejemplo de Estructura de Nodos

Nodo 1 → Nodo 2 → Nodo 3 → None
  • Nodo 1 tiene un valor (dato) y un enlace (referencia) al Nodo 2.
  • Nodo 2 tiene un valor (dato) y un enlace (referencia) al Nodo 3.
  • Nodo 3 tiene un valor (dato) y su enlace es None, indicando el final de la lista.

class ListaEnlazada:
    def __init__(self):
        self.cabeza = None  # El primer nodo de la lista

    # Método para agregar un nuevo nodo al principio de la lista
    def agregar_al_inicio(self, datos):
        nuevo_nodo = Nodo(datos)
        nuevo_nodo.siguiente = self.cabeza  # El nuevo nodo apunta al antiguo "cabeza"
        self.cabeza = nuevo_nodo  # Actualizamos "cabeza" al nuevo nodo

    # Método para imprimir la lista
    def imprimir_lista(self):
        actual = self.cabeza  # Comenzamos desde la cabeza
        while actual:  # Mientras existan nodos
            print(actual.datos, end=" -> ")
            actual = actual.siguiente
        print("None")

    # Método para agregar un nodo al final de la lista
    def agregar_al_final(self, datos):
        nuevo_nodo = Nodo(datos)
        if not self.cabeza:  # Si la lista está vacía
            self.cabeza = nuevo_nodo
            return
        actual = self.cabeza
        while actual.siguiente:  # Navegamos hasta el último nodo
            actual = actual.siguiente
        actual.siguiente = nuevo_nodo  # El último nodo apunta al nuevo nodo

    # Método para eliminar un nodo con un valor específico
    def eliminar(self, datos):
        actual = self.cabeza

        # Caso especial: Si el nodo a eliminar es la cabeza
        if actual and actual.datos == datos:
            self.cabeza = actual.siguiente  # Actualizamos la cabeza
            actual = None
            return

        anterior = None
        while actual and actual.datos != datos:
            anterior = actual
            actual = actual.siguiente

        if not actual:  # Si no se encuentra el nodo
            print(f"El valor {datos} no está en la lista.")
            return

        anterior.siguiente = actual.siguiente
        actual = None

Lista Circular en Python

Las listas circulares en Python son estructuras de datos donde el último elemento está conectado de nuevo al primer elemento, formando un bucle. Se pueden implementar de varias maneras, dependiendo del contexto y el propósito.

🚀 Concepto de Lista Circular

Una lista circular es una variante de una lista enlazada en la que el último nodo apunta al primero en lugar de None. Esto permite recorrer la lista de manera continua sin llegar a un final definido.

🔹 Implementaciones en Python

    def __init__(self, elementos):
        self.elementos = elementos

    def obtener(self, indice):
        return self.elementos[indice % len(self.elementos)]

            self.cabeza = nuevo_nodo
            self.cabeza.siguiente = self.cabeza  # Se apunta a sí mismo
        else:
            temp = self.cabeza
            while temp.siguiente != self.cabeza:  # Buscar el último nodo
                temp = temp.siguiente
            temp.siguiente = nuevo_nodo
            nuevo_nodo.siguiente = self.cabeza  # Último apunta al primero

    def mostrar(
        self, n=10
    ):  # Muestra los primeros 'n' elementos para evitar bucles infinitos
        if not self.cabeza:
            return
        temp = self.cabeza
        for _ in range(n):
            print(temp.dato, end=" → ")
            temp = temp.siguiente
        print("...")

Introducción a la Recursión

Una función recursiva en Python (o en cualquier lenguaje de programación) es una función que se llama a sí misma, directa o indirectamente, para resolver un problema dividiéndolo en subproblemas más pequeños del mismo tipo. Generalmente, una función recursiva se compone de dos partes principales:

  1. Caso base (o condición de parada): Este es el caso en el que la función no se llama a sí misma, evitando un bucle infinito. Define cuándo el problema ya no necesita dividirse más y se puede resolver directamente.

  2. Caso recursivo: Aquí, la función se llama a sí misma con un conjunto reducido o simplificado de datos, acercándose al caso base.

Estructura básica de una función recursiva

def funcion_recursiva(parametro):
    if condicion_base:  # Caso base
        return resultado_base
    else:  # Caso recursivo
        return funcion_recursiva(parametro_reducido)

Ejemplo: Factorial de un número

El factorial de un número 𝑛 (denotado como 𝑛!) es el producto de todos los números enteros positivos desde 1 hasta 𝑛. Se define como:

    𝑛! = 1 si 𝑛 = 0 (caso base).
    
    𝑛! = 𝑛 × (𝑛−1)! si 𝑛 > 0 (caso recursivo).

La implementación recursiva sería:

In [2]:
def factorial(n):
    if n == 0:  # Caso base
        return 1
    else:  # Caso recursivo
        return n * factorial(n - 1)

# Prueba
print(factorial(5))  # Salida: 120

120

Explicación del Código

  1. Llamamos factorial(5).

  2. La función evalúa:

    5 × 𝑓𝑎𝑐𝑡𝑜𝑟𝑖𝑎𝑙(4).
  1. Para calcular factorial(4), evalúa:
    4 × 𝑓𝑎𝑐𝑡𝑜𝑟𝑖𝑎𝑙(3).

  1. Y así sucesivamente hasta llegar a factorial(0), que devuelve 1 (caso base).

  2. Luego, los resultados de las multiplicaciones se combinan al regresar de las llamadas.

Ventajas y desventajas

Ventajas:

  • Elegancia y simplicidad en problemas que tienen una estructura naturalmente recursiva (como recorridos de árboles, problemas de subdivisión, etc.).

Desventajas:

  • Puede consumir mucha memoria (debido al almacenamiento de las llamadas en la pila de ejecución).
  • Puede ser menos eficiente que una solución iterativa si no se optimiza adecuadamente.

Consideraciones Importantes

  1. Caso Base: Es esencial para evitar un bucle infinito.
  2. Reducción del Problema: La función debe progresar hacia el caso base con cada llamada recursiva.
  3. Ejemplo de Error Común: Si olvidamos el caso base o no reducimos correctamente el problema, la recursión no terminará.

Conclusión

La recursión es una herramienta poderosa para resolver problemas que pueden descomponerse en subproblemas similares. Siempre debemos definir un caso base para evitar bucles infinitos y asegurarnos de que cada llamada recursiva acerca el problema al caso base.

¡Eso es todo para esta introducción a la recursión!

Árboles en Programación

Introducción

Un árbol es una estructura de datos jerárquica donde:

  • Existe un nodo principal, llamado nodo raíz.
  • De la raíz se desprenden nodos hijos.
  • Cada nodo puede tener padres y hijos.
  • Los nodos hojas son aquellos que no tienen hijos.

Ejemplo de un Árbol

En un árbol, los nodos están conectados por enlaces:

  • El nodo A tiene dos hijos: B y C.
  • C puede tener a su vez hijos como F y G.
  • Todos los nodos tienen un padre único, pero pueden tener varios hijos.

Si un nodo tiene como máximo dos hijos, el árbol se denomina un árbol binario.

Recorridos en un árbol binario

En esta sección, exploramos las distintas formas de recorrer un árbol binario. Los recorridos más comunes son:

  1. Preorder (Preorden): Se visita primero la raíz, luego el subárbol izquierdo y finalmente el subárbol derecho.

  3. Postorder (Postorden): Se visita primero el subárbol izquierdo, luego el subárbol derecho y finalmente la raíz.

Introducción a los Grafos

Un grafo es una estructura matemática utilizada para modelar relaciones entre objetos. Está compuesto por:

  • Vértices: Representan los puntos o nodos del grafo. Cada vértice tiene un nombre único (clave) y puede contener información adicional llamada carga.
  • Aristas: Representan los enlaces entre los vértices. Una arista puede ser:
    • Dirigida: Tiene un sentido específico (de un vértice a otro).
    • No dirigida: El enlace es bidireccional entre los vértices.

Componentes de un Grafo

1. Vértices

Los vértices son los nodos del grafo. Por ejemplo:

  • V = {1, 2, 3, 4, 5, 6}

2. Aristas

Las aristas conectan dos vértices. Se representan como una tupla (u, v), donde u y v son vértices.

Ejemplo:

  • A = {(1, 2), (1, 4), (2, 4), (2, 3), (3, 5), (4, 5), (5, 6)}

3. Pesos

Las aristas pueden tener un peso asociado, que representa la "distancia", "costo", u otra métrica entre los vértices.

Definiciones Importantes

1. Camino

Un camino es una secuencia de aristas que conecta un vértice inicial con otro vértice del grafo. Por ejemplo:

  • Camino: 1 → 4 → 5 → 6

2. Ciclo

Un ciclo es un camino que empieza y termina en el mismo vértice, pasando por otros vértices intermedios. Por ejemplo:

  • Ciclo: 1 → 4 → 2 → 1

Aplicaciones de los Grafos

Los grafos son utilizados en diversas áreas, como:

  • Redes de computadoras
  • Sistemas de transporte
  • Modelos sociales
  • Diseño de circuitos

Esta representación nos permite visualizar claramente cómo los vértices y las aristas interactúan dentro de un grafo.

Matriz de Adyacencia

La matriz de adyacencia es una forma de representar grafos utilizando una matriz en la que las filas y columnas representan los vértices, y los valores en las celdas indican la presencia de aristas entre ellos.

Características Generales

  • Cada fila y columna corresponde a un vértice del grafo.

  • El valor en la intersección de una fila y una columna indica si existe una conexión (arista) entre los dos vértices.

    • 1: Existe una conexión.
    • 0: No existe conexión.

Grafo No Dirigido

En un grafo no dirigido, las conexiones no tienen dirección, por lo que la matriz es simétrica. Cada arista entre dos nodos se representa de la misma forma en ambas direcciones.

Ejemplo:

1 -- 2 -- 3
|         |
4 --------5

Matriz de adyacencia:

   1  2  3  4  5
1: 0  1  0  1  0
2: 1  0  1  0  0
3: 0  1  0  0  1
4: 1  0  0  0  1
5: 0  0  1  1  0

Notas:

  • El valor de la celda [1,2] y [2,1] es 1, indicando que hay una arista entre los vértices 1 y 2.

  • Los bucles se representan como valores en la diagonal principal.

Grafo Dirigido

En un grafo dirigido, las conexiones tienen dirección, lo que implica que [𝑖,𝑗]y [𝑗,𝑖] pueden tener valores diferentes.

Ejemplo:

1 → 2 → 3
↑    ↓
4 ←  5

Matriz de adyacencia:

   1  2  3  4  5
1: 0  1  0  0  0
2: 0  0  1  0  1
3: 0  0  0  0  0
4: 1  0  0  0  0
5: 0  0  0  1  0

Notas:

  • En la celda [1,2] hay un 1, indicando que existe una arista de 1 a 2.

  • En la celda [2,1] hay un 0, indicando que no existe arista en la dirección opuesta.

Grafos Ponderados

En un grafo ponderado, las aristas tienen un peso asociado. La matriz de adyacencia almacena estos pesos en lugar de un simple 1.

Ejemplo:

A --4--> B --2--> C
|        |        ↓
4        1        D
↓        ↓        
E        F

Matriz de adyacencia:

    A  B  C  D  E  F
A:  0  4  0  0  4  0
B:  0  0  2  0  0  1
C:  0  0  0  4  0  0
D:  0  0  0  0  0  0
E:  4  0  0  0  0  0
F:  0  0  0  0  0  0

Notas:

  • En la celda [𝐴,𝐵] hay un 4, indicando que la arista de A a B tiene un peso de 4.

  • Si no hay conexión entre dos vértices, el valor es 0.

Limitaciones de la Matriz de Adyacencia

  • Eficiencia: Almacena muchas celdas vacías (valores 0), especialmente en grafos dispersos.
  • Espacio: Utiliza mucho espacio para grafos con gran cantidad de vértices y pocas conexiones.

Por estas razones, en algunos casos se prefiere utilizar la lista de adyacencia, que solo almacena las conexiones existentes.

Conclusión

La matriz de adyacencia es una representación sencilla y clara de un grafo, pero puede ser ineficiente para grafos con pocas aristas. Dependiendo del tipo de grafo (dirigido, no dirigido o ponderado), esta matriz puede variar en contenido y estructura.

Para grafos grandes o dispersos, es más eficiente usar una lista de adyacencia.

Lista de Adyacencia

La lista de adyacencia es una representación de todas las aristas de un grafo mediante listas. A diferencia de la matriz de adyacencia, esta técnica se enfoca en almacenar únicamente las conexiones entre los vértices que realmente existen, haciendo que sea más eficiente en términos de espacio.

Concepto General

La lista de adyacencia:

  • Representa un grafo como un conjunto de listas, donde cada vértice tiene una lista que contiene los nodos a los que está conectado.

  • Es eficiente porque solo almacena las aristas (conexiones) existentes, eliminando la redundancia de celdas vacías de una matriz de adyacencia.

Ejemplo: Grafo No Dirigido

En un grafo no dirigido, las conexiones entre los vértices son bidireccionales y se representan con conjuntos.

Por ejemplo:

1 -- 2
1 -- 4
2 -- 3

La lista de adyacencia sería:

In [2]:
grafo = {
    1: {2, 4},
    2: {1, 3},
    3: {2},
    4: {1}
}

  • El vértice 1 está conectado con 2 y 4.

  • El vértice 2 está conectado con 1 y 3.

  • Los conjuntos son simétricos, ya que no importa el orden en un grafo no dirigido.

Ejemplo: Grafo Dirigido

En un grafo dirigido, las conexiones tienen una dirección específica. En este caso, utilizamos tuplas para representar las aristas como pares ordenados (origen, destino).

Por ejemplo:

1 → 2
1 → 4
2 → 3

La lista de adyacencia sería:

In [3]:
grafo = {
    1: [(2,), (4,)],
    2: [(3,)],
    3: [],
    4: []
}
  • El vértice 1 tiene dos salidas: una hacia 2 y otra hacia 4.
  • El vértice 2 tiene una salida hacia 3.
  • Los vértices 3 y 4 no tienen conexiones salientes, por lo que sus listas están vacías.

Nota: Las tuplas indican que la conexión es direccional. Por ejemplo, (1, 2) significa que hay una conexión de 1 a 2, pero no de 2 a 1.

No Dirigido Conjuntos {} {1: {2, 4}, 2: {1, 3}, 3: {2}, 4: {1}}
Dirigido Listas de tuplas [] {1: [(2,), (4,)], 2: [(3,)], 3: [], 4: []}

Ventajas de la Lista de Adyacencia

  1. Eficiencia en el uso de memoria:

    • No almacena celdas vacías para vértices que no tienen conexión.

  2. Flexibilidad:

    • Puede representar tanto grafos dirigidos como no dirigidos de forma clara.

  3. Fácil manipulación:

    • Añadir o eliminar aristas es más sencillo en comparación con una matriz de adyacencia.

Conclusión

La lista de adyacencia es una manera más eficiente de implementar un grafo, especialmente cuando el grafo es disperso (pocos vértices conectados entre sí). Esta representación no solo ahorra espacio, sino que también facilita la manipulación y comprensión de las conexiones en el grafo.

Algoritmo de Búsqueda Secuencial en Python

La búsqueda secuencial es un algoritmo que recorre una estructura de datos (por ejemplo, una lista) y compara cada elemento con el valor que se desea encontrar. Si encuentra una coincidencia, detiene la búsqueda y devuelve el resultado.

A continuación, se explica cómo implementarlo en Python.

Implementación

  1. Definir la función búsqueda_secuencial:

    • Parámetros:
      • lista: Lista de elementos donde se realizará la búsqueda.
      • elemento: El valor que queremos buscar en la lista.
    • Retorno:
      • True si el elemento se encuentra en la lista.
      • False si el elemento no está presente.

  2. Pasos del algoritmo:

    • Inicializar:
      • posición: La posición actual en la lista (inicia en 0).
      • encontrado: Variable booleana (False) que indica si el elemento ha sido encontrado.
    • Recorrer la lista secuencialmente mientras:
      • La posición actual sea menor que la longitud de la lista.
      • No se haya encontrado el elemento.
    • Si el valor en la posición actual coincide con el elemento, actualizar encontrado a True.
    • Si no coincide, avanzar a la siguiente posición.
    • Al final del bucle, retornar el valor de encontrado.
In [5]:
def búsqueda_secuencial(lista, elemento):
    posición = 0  # Posición inicial
    encontrado = False  # Variable booleana para indicar si se encuentra el elemento

    # Recorrer la lista
    while posición < len(lista) and not encontrado:
        if lista[posición] == elemento:
            encontrado = True  # Elemento encontrado
        else:
            posición += 1  # Avanzar a la siguiente posición

    return encontrado

Algoritmo de Búsqueda Secuencial para una Lista Ordenada en Python

La búsqueda secuencial en una lista ordenada es una variante del algoritmo de búsqueda secuencial. Aprovecha que los datos están ordenados para detener la búsqueda en cuanto se encuentra un valor mayor al buscado, lo que mejora la eficiencia en ciertos casos.

Implementación

  1. Definir la función busqueda_secuencial_ordenada:

    • Parámetros:
      • lista: Lista de elementos ordenados.
      • elemento: El valor que queremos buscar en la lista.
    • Variables iniciales:
      • posicion: Comienza en 0 y representa la posicion actual.
      • encontrado: Variable booleana que indica si el elemento ha sido encontrado (False inicialmente).
      • parar: Variable booleana que indica si se debe detener la búsqueda (False inicialmente).

  2. Lógica del algoritmo:

    • Mientras:
      • posicion sea menor que la longitud de la lista.
      • No se haya encontrado el elemento (encontrado == False).
      • No se haya activado la variable parar.
    • Comparar el valor actual en la lista con el elemento buscado:
      • Si son iguales, actualizar encontrado a True.
      • Si el valor actual es mayor que el elemento, activar parar para detener la búsqueda.
      • Si es menor, avanzar a la siguiente posicion.
    • Retornar el valor de encontrado al final del bucle.

Código en Python

def busqueda_secuencial_ordenada(lista, elemento):
    posicion = 0
    encontrado = False
    parar = False

    while posicion < len(lista) and not encontrado and not parar:
        if lista[posicion] == elemento:
            encontrado = True
        elif lista[posicion] > elemento:
            parar = True
        else:
            posicion += 1

    return encontrado

Algoritmo de Búsqueda Binaria en Python

La búsqueda binaria es un algoritmo eficiente que encuentra un elemento en una lista ordenada. Su principal ventaja es que reduce el espacio de búsqueda a la mitad en cada iteración, aprovechando que los datos están ordenados.

Concepto del Algoritmo

  1. Selecciona el valor medio de la lista:

    • Si el valor medio es igual al elemento buscado, la búsqueda termina.
    • Si el elemento buscado es menor, busca en la mitad izquierda.
    • Si el elemento buscado es mayor, busca en la mitad derecha.

  2. Repite este proceso en la mitad correspondiente hasta encontrar el elemento o hasta que no queden elementos por buscar.

Implementación en Python

Pasos del Algoritmo

  1. Inicializar:

    • primero: Índice del primer elemento (inicia en 0).
    • ultimo: Índice del ultimo elemento (len(lista) - 1).
    • encontrado: Variable booleana para indicar si el elemento fue encontrado (False inicialmente).

  2. Mientras:

    • primero <= ultimo y encontrado == False:
      • Calcular el índice medio (medio).
      • Comparar el valor medio con el elemento buscado:
        • Si son iguales, actualizar encontrado a True.
        • Si el elemento buscado es menor, mover ultimo al índice medio - 1.
        • Si el elemento buscado es mayor, mover primero al índice medio + 1.

  3. Retornar el valor de encontrado.

Codigo

def busqueda_binaria(lista, elemento):
    primero = 0
    ultimo = len(lista) - 1
    encontrado = False

    while primero <= ultimo and not encontrado:
        medio = (primero + ultimo) // 2  # Calcular el índice medio

        if lista[medio] == elemento:
            encontrado = True
        elif elemento < lista[medio]:
            ultimo = medio - 1  # Buscar en la mitad izquierda
        else:
            primero = medio + 1  # Buscar en la mitad derecha

    return encontrado

Algoritmo de Ordenación de Burbuja

El algoritmo de ordenación de burbuja (o Bubble Sort en inglés) es un método sencillo de ordenamiento que:

  1. Compara cada par de elementos adyacentes en la lista.

  2. Intercambia sus posiciones si están en el orden incorrecto.

  3. Repite este proceso hasta que no se necesiten más intercambios, lo que indica que la lista está ordenada.

Funcionamiento del Algoritmo

El proceso es el siguiente:

  1. Recorremos toda la lista comparando cada elemento con el siguiente.

  2. Si los elementos están en un orden incorrecto, se intercambian.

  3. Al final de cada iteración, el elemento más grande "sube" a su posición final.

  4. Repetimos el proceso hasta que toda la lista esté ordenada.

Ejemplo

Dada la lista: [6, 5, 3, 1]

  1. Comparamos 6 y 5: intercambiamos → [5, 6, 3, 1].

  2. Comparamos 6 y 3: intercambiamos → [5, 3, 6, 1].

  3. Comparamos 6 y 1: intercambiamos → [5, 3, 1, 6].

  4. Repetimos el proceso para ordenar completamente la lista.

Implementación en Python

Definición de la Función

La función realiza el ordenamiento utilizando dos bucles:

In [1]:
def bubble_sort(arr):
    n = len(arr)
    for i in range(n - 1):
        # El rango de comparación se reduce con cada iteración
        for j in range(n - i - 1):
            if arr[j] > arr[j + 1]:
                # Intercambiar si el elemento actual es mayor que el siguiente
                arr[j], arr[j + 1] = arr[j + 1], arr[j]

Desglose del Código

  1. Bucle Externo:

    • Recorre la lista desde el final hasta el principio, reduciendo el rango en cada iteración.

  2. Bucle Interno:

    • Compara cada par de elementos adyacentes.

  3. Intercambio:

    • Si los elementos están desordenados, los intercambiamos. Esto se hace usando una asignación múltiple en Python, lo que resulta muy conveniente y claro.

Algoritmo de Ordenación por Selección | Selection Sort

El algoritmo de ordenación por selección (Selection Sort) es un método sencillo pero ineficiente para ordenar una lista. Su idea principal es recorrer la lista repetidamente, seleccionando en cada iteración el elemento más pequeño (o más grande, dependiendo del orden deseado) del subconjunto desordenado y colocándolo en su posición final correspondiente.

Cómo funciona Selection Sort:

  1. Dividir la lista en dos partes:

    • Una parte ya ordenada (al principio, vacía) y otra desordenada.

  2. Buscar el elemento mínimo (o máximo):

    • Recorrer el subconjunto desordenado para encontrar el valor más pequeño.

  3. Intercambiar posiciones:

    • Cambiar la posición del elemento mínimo con el primer elemento del subconjunto desordenado, expandiendo así la parte ordenada en una posición más.

  4. Repetir el proceso:

    • Continuar este procedimiento para el resto de la lista hasta que todos los elementos estén en la parte ordenada.

Ejemplo

Dada la lista: [6, 5, 3, 1]

  1. Encuentra el valor máximo: 6. Lo intercambia con el último elemento → [1, 5, 3, 6].

  2. Encuentra el siguiente máximo: 5. Lo intercambia con el penúltimo → [1, 3, 5, 6].

  3. Repite el proceso hasta que la lista esté ordenada: [1, 3, 5, 6].

Implementación en Python

Definición de la Función

La función utiliza dos bucles para encontrar el valor máximo y colocarlo en su posición correcta.

def selection_sort(arr):
    n = len(arr)
    for i in range(n):
        # Suponemos que el primer elemento del segmento desordenado es el mínimo
        min_index = i
        # Encontrar el índice del elemento más pequeño
        for j in range(i + 1, n):
            if arr[j] < arr[min_index]:
                min_index = j
        # Intercambiar el elemento más pequeño con el primer elemento del segmento desordenado
        arr[i], arr[min_index] = arr[min_index], arr[i]

Desglose del Código

  1. Bucle Externo: Itera desde el índice 0 hasta el final de la lista (n), marcando el inicio del segmento no ordenado.

  2. Bucle Interno: Busca el índice del valor mínimo en el segmento no ordenado (del índice actual i hasta el final).

  3. Intercambio: Una vez encontrado el valor mínimo, lo intercambia con el valor que está en la posición i, moviéndolo a su posición correcta en el segmento ordenado.

Explicación del Algoritmo

Vamos a analizar el código paso a paso:

  • Aquí definimos la función selection_sort que recibe como parámetro arr, la lista que queremos ordenar.
n = len(arr)
  • Calculamos el tamaño de la lista y lo almacenamos en n. Esto nos ayudará a limitar los bucles de iteración.

  • Este es el bucle principal. Recorremos todos los índices de la lista, y en cada iteración del bucle tratamos de encontrar el elemento más pequeño en el segmento desordenado (inicialmente toda la lista) para moverlo a su posición correcta.
min_index = i
  • Inicialmente asumimos que el primer elemento del segmento actual (arr[i]) es el más pequeño. Guardamos su índice en min_index.
for j in range(i + 1, n):
    if arr[j] < arr[min_index]:
        min_index = j

  • Este es el bucle interno. Su tarea es buscar el elemento más pequeño en el segmento desordenado de la lista. Comienza justo después de i (en i+1) y recorre hasta el final.

  • Si encuentra un elemento arr[j] que es más pequeño que el actual arr[min_index], actualiza min_index con el índice de este nuevo elemento más pequeño.

  • Una vez que el bucle interno termina, min_index contiene la posición del elemento más pequeño en el segmento desordenado.

  • Intercambiamos el elemento en arr[i] con el elemento en arr[min_index]. Esto coloca el elemento más pequeño en la posición i, expandiendo la parte ordenada de la lista.

Después de que el bucle externo haya recorrido todos los índices, la lista estará ordenada. El proceso esencialmente "selecciona" el siguiente elemento más pequeño en cada iteración y lo coloca en la posición correcta, desde el principio de la lista hasta el final.

Resumen del proceso:

  1. Suponemos que el primer elemento del segmento desordenado es el más pequeño.

  2. Recorremos el resto del segmento buscando un elemento aún más pequeño.

  3. Si encontramos un elemento menor, actualizamos el índice del mínimo.

  4. Al final de la iteración, intercambiamos el elemento más pequeño encontrado con el elemento inicial del segmento desordenado.

  5. Repetimos estos pasos hasta que toda la lista esté ordenada.

Complejidad del Algoritmo

  • Complejidad temporal: O(n²) en el mejor, promedio y peor caso, ya que siempre realiza la misma cantidad de comparaciones.

  • Complejidad espacial: O(1), porque no utiliza memoria adicional significativa.

  • Estabilidad: Selection Sort no es estable por defecto, ya que intercambia elementos sin considerar si tienen el mismo valor.

Conclusión

El algoritmo de ordenación por selección es más eficiente que el algoritmo de burbuja en cuanto al número de intercambios, ya que realiza uno por iteración. Sin embargo, sigue siendo ineficiente para listas grandes debido a su complejidad cuadrática.

Algoritmo de Ordenación por Inserción

El algoritmo de ordenación por inserción es una forma muy natural de ordenar elementos, similar a cómo lo haría un ser humano. A continuación, se explica su funcionamiento:

  1. Va tomando cada elemento de la lista y lo posiciona en el lugar que le corresponde dentro de una sublista ordenada.

  2. Al llegar al último elemento y colocarlo en su posición correcta, la lista completa estará ordenada.

  3. Mantiene una lista ordenada en las posiciones más bajas mientras avanza por los elementos de la lista original.

Ejemplo

Si tenemos la lista: 6, 4, 5, 1, 3

  1. Empezamos con el segundo elemento (posición 1): 4.

    • Comparamos el 4 con el elemento en la posición anterior (6).
    • Insertamos el 4 antes del 6. La lista queda: 4, 6.

  2. Continuamos con el tercer elemento (posición 2): 5.

    • Comparamos el 5 con los elementos de la sublista ordenada (4, 6).
    • Insertamos el 5 entre 4 y 6. La lista queda: 4, 5, 6.

  3. Seguimos con el cuarto elemento (posición 3): 1.

    • Comparamos el 1 con los elementos de la sublista ordenada (4, 5, 6).
    • Insertamos el 1 al principio. La lista queda: 1, 4, 5, 6.

  4. Finalmente, tomamos el último elemento (posición 4): 3.

    • Comparamos el 3 con los elementos de la sublista ordenada (1, 4, 5, 6).
    • Insertamos el 3 en su lugar correspondiente. La lista queda: 1, 3, 4, 5, 6.

Al final, la lista está completamente ordenada.

Implementación en Python

def ordenacion_por_insercion(lista):
    # Recorremos la lista desde el segundo elemento
    for indice in range(1, len(lista)):
        # Guardamos el valor actual y su posición inicial
        valor = lista[indice]
        posicion = indice

        # Reubicamos el valor en la sublista ordenada
        while posicion > 0 and lista[posicion - 1] > valor:
            lista[posicion] = lista[posicion - 1]
            posicion -= 1

        # Insertamos el valor en la posición correcta
        lista[posicion] = valor

  1. Primer bucle (for): Recorre la lista comenzando desde el segundo elemento.

  2. Variables valor y posicion:

    • valor: Almacena el elemento actual.
    • posicion: Representa la posición actual del elemento en la lista.

  3. Segundo bucle (while):

    • Compara el elemento actual con los de la sublista ordenada.
    • Mueve los elementos mayores una posición hacia la derecha.

  4. Inserción: Una vez encontrado el lugar correcto, se asigna el valor en la posición correspondiente.

Resultado Final

Después de aplicar el algoritmo a una lista, los elementos estarán ordenados de forma ascendente. Este método es intuitivo y fácil de entender, aunque su rendimiento puede no ser óptimo para listas grandes debido a su complejidad 𝑂(𝑛2).

Algoritmo de Ordenación Shell | Shell Sort

El Algoritmo de Ordenación Shell (Shell Sort) es una mejora del algoritmo de ordenación por inserción. Introduce la idea de trabajar con elementos separados por ciertos intervalos (gaps), reduciendo este intervalo de manera progresiva hasta que se realiza una ordenación final con un intervalo de 1.

Características del Shell Sort:

  1. Es un algoritmo basado en comparación e intercambio.

  2. Mejora la eficiencia del ordenamiento al permitir intercambios de elementos lejanos.

  3. La eficiencia depende en gran medida de la secuencia de intervalos (gaps) utilizada.

Algoritmo General:

  1. Inicialización:

    • Elegir una secuencia de intervalos (por ejemplo, n/2, n/4, ..., 1).

  2. Ordenación por sublistas:

    • Para cada intervalo, ordenar los elementos separados por ese intervalo usando una versión modificada de la ordenación por inserción.

  3. Reducir el intervalo:

    • Repetir el proceso con intervalos más pequeños hasta que el intervalo sea 1.

Código en Python:

Aquí tienes una implementación del Shell Sort:

In [4]:
def shell_sort(arr):
    n = len(arr)
    gap = n // 2  # Inicia con un intervalo grande
    
    while gap > 0:
        # Ordena los elementos separados por el intervalo actual
        for i in range(gap, n):
            temp = arr[i]
            j = i
            # Mueve los elementos que están fuera de lugar
            while j >= gap and arr[j - gap] > temp:
                arr[j] = arr[j - gap]
                j -= gap
            arr[j] = temp
        
        # Reduce el intervalo
        gap //= 2
    
    return arr

Explicación del Código

  1. Inicio del intervalo:

    • El intervalo inicial es la mitad del tamaño del arreglo.

  2. Ordenación interna:

    • Para cada elemento en la sublista definida por el intervalo, se usa una variación del método de inserción para colocarlo en su posición.

  3. Reducir el intervalo:

    • El intervalo se reduce dividiéndolo entre 2 hasta llegar a 1.

  4. Finalización:

    • Cuando el intervalo es 1, se realiza una última pasada que asegura que el arreglo está completamente ordenado.

Complejidad:

  • Mejor caso: O(n log n) (dependiendo de la secuencia de intervalos).

  • Peor caso: O(n**2) (con una mala elección de intervalos, como potencias de 2).

  • Promedio: Entre O(n log2 n) y O(n1.5).

Conclusión

El Shell Sort es eficiente para tamaños de datos moderados y es fácil de implementar. Sin embargo, para datos muy grandes, otros algoritmos como Merge Sort o Quick Sort suelen ser más rápidos.

Algoritmo de Ordenación por Mezcla

El algoritmo de ordenación por mezcla es un método recursivo que divide continuamente una lista en mitades, las ordena y luego las une para obtener una lista completamente ordenada.

Funcionamiento

  1. División de la lista:

    • Se divide la lista en dos mitades hasta que cada sublista tenga un solo elemento (una lista de un elemento ya está ordenada).

  2. Ordenación recursiva:

    • Se llama al mismo algoritmo para ordenar cada mitad de manera recursiva.

  3. Mezcla de las sublistas:

    • Se comparan los elementos de las sublistas y se combinan en una nueva lista ordenada.

Implementación en Python

Función Principal: ordenacion_mezcla

def ordenacion_mezcla(lista):
    # Verificar si la lista tiene más de un elemento
    if len(lista) > 1:
        # Calcular el punto medio de la lista
        medio = len(lista) // 2

        # Dividir la lista en dos mitades
        izquierda = lista[:medio]
        derecha = lista[medio:]

        # Ordenar cada mitad recursivamente
        ordenacion_mezcla(izquierda)
        ordenacion_mezcla(derecha)

        # Mezclar las dos mitades
        i = j = k = 0

        # Mezclar elementos ordenados de izquierda y derecha
        while i < len(izquierda) and j < len(derecha):
            if izquierda[i] < derecha[j]:
                lista[k] = izquierda[i]
                i += 1
            else:
                lista[k] = derecha[j]
                j += 1
            k += 1

        # Añadir los elementos restantes de la izquierda
        while i < len(izquierda):
            lista[k] = izquierda[i]
            i += 1
            k += 1

        # Añadir los elementos restantes de la derecha
        while j < len(derecha):
            lista[k] = derecha[j]
            j += 1
            k += 1

Explicación del Código

  1. División:

    • Calcula el punto medio de la lista con medio = len(lista) // 2.
    • Divide la lista en dos mitades: izquierda y derecha.

  2. Ordenación Recursiva:

    • Llama recursivamente a ordenacion_mezcla para ordenar las mitades.

  3. Mezcla de Sublistas:

    • Compara los elementos de las dos sublistas (izquierda y derecha).
    • Inserta el elemento menor en la lista principal.
    • Continúa hasta que todos los elementos de ambas sublistas se hayan insertado.

  4. Añadir Elementos Restantes:

    • Los elementos que no se han mezclado (porque una sublista es más larga) se añaden al final.

Proceso de Ordenación

  1. Divide la lista:

    • Izquierda: [4, 1]
    • Derecha: [9, 3, 10]

  2. Ordena cada mitad:

    • Izquierda ordenada: [1, 4]
    • Derecha ordenada: [3, 9, 10]

  3. Mezcla las mitades:

    • Combina [1, 4] y [3, 9, 10] para obtener [1, 3, 4, 9, 10].

Conclusión

El algoritmo de ordenación por mezcla es eficiente y utiliza el paradigma divide y vencerás. Tiene una complejidad de 𝑂(𝑛log𝑛), lo que lo hace adecuado para listas grandes.

Algoritmo de Ordenación Rápida (QuickSort)

El algoritmo de ordenación rápida es un método recursivo que utiliza un elemento llamado pivote para dividir la lista en dos partes: una con los elementos menores que el pivote y otra con los mayores. A continuación, se aplica el mismo proceso a cada sublista hasta que toda la lista esté ordenada.

Funcionamiento

  1. Elegir un pivote:

    • Generalmente, se toma el primer elemento de la lista como pivote.

  2. Dividir la lista:

    • Se separan los elementos en tres listas:
      • Izquierda: Elementos menores que el pivote.
      • Centro: Elementos iguales al pivote.
      • Derecha: Elementos mayores que el pivote.

  3. Ordenación recursiva:

    • Aplicar recursivamente el algoritmo a las listas de la izquierda y la derecha.

  4. Combinar las listas:

    • Unir las listas izquierda, centro y derecha para formar la lista final ordenada.

Implementación en Python

def ordenamiento_rapido(lista):
    # Caso base: lista con 0 o 1 elemento ya está ordenada
    if len(lista) <= 1:
        return lista

    # Elegimos el pivote (primer elemento)
    pivote = lista[0]

    # Dividimos en tres listas: izquierda, centro y derecha
    izquierda = []
    centro = []
    derecha = []

    # Clasificamos los elementos según el pivote
    for elemento in lista:
        if elemento < pivote:
            izquierda.append(elemento)
        elif elemento == pivote:
            centro.append(elemento)
        else:
            derecha.append(elemento)

    # Llamadas recursivas y combinación de listas
    return ordenamiento_rapido(izquierda) + centro + ordenamiento_rapido(derecha)

Explicación del Código

  1. Caso base:

    • Si la lista tiene 0 o 1 elemento, ya está ordenada y se retorna tal cual.

  2. Selección del pivote:

    • Se toma el primer elemento como pivote, pero puede ser cualquier elemento.

  3. División de la lista:

    • Los elementos menores que el pivote se añaden a izquierda.
    • Los elementos iguales al pivote se añaden a centro.
    • Los elementos mayores que el pivote se añaden a derecha.

  4. Ordenación recursiva:

    • Se aplica el algoritmo a las listas izquierda y derecha.

  5. Combinar resultados:

    • Las listas ordenadas de izquierda, centro y derecha se concatenan para formar la lista final.

Ejemplo de Ejecución

Proceso de Ordenación

  1. Elegimos el pivote: 4.

    • Izquierda: [1, 3]
    • Centro: [4]
    • Derecha: [9, 8]

  2. Ordenamos recursivamente:

    • Izquierda: [1, 3] → ya está ordenada.
    • Derecha: [9, 8] → Pivote: 9, Izquierda: [8], Centro: [9], Derecha: [] → Ordenada: [8, 9].

  3. Combinamos:

    • Resultado final: [1, 3] + [4] + [8, 9] → [1, 3, 4, 8, 9].

Conclusión

El algoritmo de ordenación rápida es eficiente y utiliza el paradigma divide y vencerás. Tiene una complejidad promedio de 𝑂(𝑛log𝑛) y es ideal para listas grandes. Sin embargo, su rendimiento puede ser peor en listas ya ordenadas o casi ordenadas si no se elige el pivote adecuadamente.
